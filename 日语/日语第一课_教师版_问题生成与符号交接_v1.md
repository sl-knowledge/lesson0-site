# 日语第一课｜教师版：认知衔接、符号交接与自主问题生成 v1

**对应教材：**《日语第一课_重写版_学生版.pdf》及同名学生版 Markdown，共 4 页。  
**使用限制：** 教师版包含学生可能发现的关系、答案、提示顺序和教学边界。**不要提前发给学生，也不要把所有问题一次性念出来。**

## 1. 本课的定位：从第零课出发，但不要重教第零课

第零课已经帮助中文母语者认识：日语可以用罗马字、平假名、片假名记录声音；汉字和假名可以共同参与书写，文字种类并不等于词的边界。第零课的核心经历，是从熟悉的中文出发，先形成预测，再看到真实日语，并修正理解。

本课因此**不用重新讲平假名、片假名或汉字史**。学生可把「私」「犬」「見た」当作三个完整的词。今天要研究的新问题只有一个：**当词语的位置允许变化时，怎样知道是谁看见了谁？**

### 真正的学习目标

1. **内容层：** 在本课的简单主动句中，发现「が」与主语（这里是看见者）相关，「を」与宾语（这里是被看见者）相关；不再只凭第一个名词推断角色。
2. **表示层：** 体验“现有线索不够 → 发明新表示 → 用真实语言对应”的过程；学生自己发明的符号只是临时支架。
3. **方法层：** 能指出自己从哪里发现问题、为什么产生预测、怎样用新句子检验。
4. **自主层：** 能在至少一个停顿点，自行提出新的、有根据的疑问；若需提示，记录支架等级，并让提示逐步退出。

## 2. 教师预先掌握的真实机制（不要直接当成讲义）

- 本课所选结构是简化的日语主动句，如「私が犬を見た」「犬を私が見た」「猫を犬が見た」。角色关系主要由「が」「を」体现；语序变化可能改变信息重点，并非所有位置都可随意交换。
- 「が」不是所有情境下恒等于“动作发出者”。更一般地，这里它标记主语；「を」常标记直接宾语，但完整用法比本课复杂。
- 「は」与「が」不是任意替换。不要在这一课预先讲完整的主题／主语体系；若学生自主提出，记录为后续真实问题。
- 「見た」可以暂作为一个整体表达“看见了”。不在第一课讲「見る → 見た」的变化，这将留给第二课由学生观察。
- 不要要求学生背诵所有日语汉字或假名。检查的核心是功能性预测，而非拼写速度。

## 3. 教学流程和按需提示

### 第 1 页｜先激活中文里已有的正确经验

**呈现：**「我看见了那只狗」「那只狗，我看见了」「那只狗看见了我」，然后「我把杯子打碎了」「杯子被我打碎了」。

**教师不要抢先总结：** 让学生先指出哪个事件相同，哪个相反。请他解释理由，而不只报选择题答案。

**可接受的发现：**“只看第一个词不够”“同一件事可以用不同表达”“中文还有‘把／被’等帮助理解的线索”。

**如果学生卡住：**

1. 轻提示：“先别看谁排第一，谁真的在看？”
2. 更具体：“第二句和第三句都先提到狗，实际看见的一方一样吗？”
3. 必要时教师示范一次比较，再让学生自己比较另一对句子。

**禁止误导：** 不要说“中文词序不重要”。本课只说明语序不是传递关系的唯一线索。

### 第 2 页｜先制造真实的信息缺口，再发明临时符号

明确声明：**这是一种人为设计的小游戏，不是正常中文，也不等于日语。**

游戏规定：词只有「我」「狗」「看见」；动词在最后；名词可以交换位置；**不能仅根据先后顺序判定看见者**。

在学生确认信息不充分之后，再提出小提示：允许在名词后贴两种不同的符号。

**关键：学生自己选择符号。** 让他分别给“看见的一方”和“被看见的一方”选记号，再将同一事件写成两种排列。记号必须跟着角色走，而不是跟着第一个位置走。

如果学生自主发明其他能解决歧义的办法（例如增加独立小词），先承认其机制有效，再介绍“词后标记”作为今天要实验的一个具体方案。**不要否定与教师预设不同的合理方案。**

**若学生卡住：**

1. “缺了哪一种信息？”
2. “能不能给‘我’和‘狗’各贴一点东西，让别人知道角色？”
3. “一种记号表示谁在看，另一种表示谁被看见。形状你自己定。”

这里的成功标准不是选对圆圈还是三角形，而是理解**符号与角色的关系**。

### 第 3 页｜真实日语与学生符号的显式交接

**呈现顺序：**

1. 提供三个完整的词：「私＝我」「犬＝狗」「見た＝看见了」。
2. 展示彩色标记的两个真句：「私が犬を見た」「犬を私が見た」，两句基本事件相同（表达重点可能不同）。
3. 请学生先观察：哪些短标记随着“我”“狗”移动？
4. **显式绑定仪式：学生亲手抄写自己的两个符号，再亲手填入相应的「が」「を」。** 不要替他填，也不要只口头宣布对应关系。
5. 完成绑定以后，**立即撤去自创符号**。下一题仅填写真正的日语：「私（　）が／犬（　）を／見た」的空格需学生自己作答，不提供另一套符号作为提示。

> **交接的关键话术：**“你发明的是一种分清角色的方法。日语用了自己的小词来实现类似的功能。你已经懂得方法，现在我们改用真实日语。”

颜色是短期的视觉支架；第一页真实例句可使用绿色「が／ga」、橙色「を／o」，以后减弱到无色。**绝不在交接之后继续使用学生自创的两个符号。**

**答案（教师核对）：** 在本课例子中，表示“看见的一方”的自创记号 ↔ 「が」；表示“被看见的一方”的自创记号 ↔ 「を」。动手 6 完整句「私が犬を見た」。

### 第 4 页｜新句预测、解释依据和问题移交

给新词「猫＝猫」，展示无颜色的新句：

**猫を犬が見た。**

**先让学生独立选择，再让他说明根据。** 本课应判为“狗看见了猫”。

如果学生答错，先问“你依据的是词序还是名词后面的小词？”；帮助他回到自己刚建立的模型。不用直接告诉他正确答案后就结束。

然后停下来：

> “今天你刚发现了一种表达办法。你现在真的想继续弄清什么？”

留一点时间，允许学生写下一句不成熟的问题。不要马上给出第二课的下一个课题。

**学生可能提出的有效问题：**“「が」「を」在所有句子里都一样吗？”“还有别的小词吗？”“「見た」为什么这样写？”“词序还能怎么换？” 这些都是由真实知识产生的问题，不要求正好符合教师准备的下一课。

## 4. 当学生提不出问题时，怎样逐级支架

在第 4 页的“好奇 9”，优先按以下顺序使用；一旦学生开始自己提问，就停止追加提示。

| 级别 | 教师给什么 | 学生还需要完成什么 |
|---|---|---|
| 0 自主 | 只展示新句并留时间 | 自己提出问题 |
| 1 轻提示 | “今天有哪个地方让你觉得还没弄清楚？” | 自己选主题、提出问题 |
| 2 对比提示 | “刚才我们只看了一个‘看见’的句型。换一种情况，你会想检查什么？” | 指出要变化的条件 |
| 3 半句 | “如果换成另一种动作，‘が’和‘を’是不是也……” | 补完并解释预测 |
| 4 示范 | 教师示范一个有依据且可检验的问题 | 学生在邻近材料上提出不同问题 |

**不应把教师示范的问题记录成学生自主提出。** 学生的问题可以是方向不对但可检验的假说；预测正确与否都能作为学习材料。

## 5. 讲完该如何评价：答对与问题生成分开记录

建议课堂只简记四种事实：

1. **内容理解：** 学生是否在无颜色的「猫を犬が見た」中识别角色，能否解释依据？
2. **符号交接：** 能否亲手完成自创符号与「が」「を」的对应，并在下一题不用旧符号？
3. **方法意识：** 能否用自己的话说明“缺少信息 → 提出办法 → 观察真实例句 → 预测”的过程？
4. **自主性：** 学生的问题原话、问题来源、所需提示级别、是否想到进一步的检验。

不要只用提出问题的数量评价学生。更有价值的是学生是否在更少提示下提出**有依据、可以进一步查证**的问题。下次给未见过的例子并减少教师提示，观察能否迁移。

## 6. 最小参考答案与边界

- 第 1 页：①、②描述的是同一基本事件；③角色颠倒。中文中的词序、话题安排、“把／被”等信息都可能帮助理解。
- 第 2 页：在本课规则下，无附加标记时信息不足；学生任意两个可区分的符号都可用于标记角色。
- 第 3 页：「私が犬を見た」「犬を私が見た」都表达“我看见狗”；显式绑定自创“看见者”记号 →「が」，自创“被看见者”记号 →「を」。
- 第 4 页：「猫を犬が見た」＝“狗看见了猫”，但此类倒装表达的语用重点需结合语境；不要把它推广为“日语可以任意排列”。

## 7. 给以后继续写教材的 AI 的交接要求

- 第一课已经**完成**自创符号 → 真实助词的交接。第二课及以后**不再重复使用自创符号**。
- 第零课已教日语文字的几种书写方式；第一课只研究简单句中角色如何标记；第二课可以用「見る／見た」开启学生自主提出“动词为什么变化”的问题。
- AI 应先研究教师后台的真实机制与例句有效性，再决定学生看到材料的顺序。**学生版不得直接复制教师版的归纳表。**
- 设计新课时至少保留一个真正的“问题交接点”：先给学生时间自行提出下一问题，再按需逐级支架。
- 一条具体日语规律只是本课的素材；真正的目标是学生能独立形成可检验预测、解释结果并产生下一轮问题。
