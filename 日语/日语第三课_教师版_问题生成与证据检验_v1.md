# 第三课｜教师版：从相似处找规律，也要检验边界

**配套学生材料：**《日语第三课_寻找规律的边界_学生版_v1》  
**定位：** 延续第零课、第一课、第二课的发现路径，训练“独立发问 → 选择有区分力的对照 → 形成可检验预测 → 修正框架 → 自主提出下一轮问题”。

> 此文件仅供教师或 AI 使用。不要把完整规律、参考答案、预设学生问题直接交给学生。学生有权沿自己真正提出的可检验问题发展支线。

## 1. 本课只追求两个学习结果

1. **语言结构：** 学生理解“看起来都以 る 结尾”不足以决定过去形式。实际上存在可以反复出现的**不同变化类别**，并不是所有词随机变化；有些类别归属不能仅凭词尾的表面形式推断，需要查证真实词汇。
2. **认知能力：** 学生自己选择比较对象、说出预测的依据与不确定性；教师在至少两处暂停，把“提出下一个问题”的权利交给学生。最后能独立提出一个可操作的检验方案，不只是答对两个过去形。

**本课不追求：** 教完日语所有动词变化、填满大量练习、强制背音读训读、完整讲解一段/五段/不规则三类术语、让每个学生问出教师预期的标准问题。

## 2. 已有知识及可用的入口

- **第零课：** 学生认识日语可由汉字与假名组合成一个词，不能把汉字后面的假名全部视为外来词或另外一个词。也已经接触罗马字读音。
- **第一课：** 学生理解了简单句 `が` / `を` 在当前例子中的功能；自创符号已完成向真实日语的交接，此后绝不再使用自创符号。
- **第二课：** 已经观察 `見る→見た`、`食べる→食べた`、`帰る→帰った`，感受到“る→た”不能推广到全部动词。

**承接方式：** 学生版第一页原样调用第二课的三组观察。先让学生自提问题，再由教师决定是否借用课程提供的“进一步检验词尾规律”路线。不要把课程预设路线谎称为学生自己提的问题。

## 3. 教师必须事先掌握的真实语言机制

现代日语的普通体过去形式在这里涉及两种类别：

- **一段动词**（ichidan，教学常称 ru-verbs / Group II）：`見る（みる / miru）→ 見た（みた / mita）`、`食べる（たべる / taberu）→ 食べた（たべた / tabeta）`、`寝る（ねる / neru）→ 寝た（ねた / neta）`。这一类的变换可描述为去掉词尾 `る`，加 `た`。
- **五段动词中以 る 结尾者**（godan，教学常称 u-verbs / Group I）：`帰る（かえる / kaeru）→ 帰った（かえった / kaetta）`、`切る（きる / kiru）→ 切った（きった / kitta）`、`走る（はしる / hashiru）→ 走った（はしった / hashitta）`。这里的普通体过去形式以 `った` 结尾。

**关键边界：** `見る（miru）` 与 `切る（kiru）` 都在发音上以 `-iru` 结尾，却属于不同类别；`食べる（taberu）` 与 `帰る（kaeru）` 都以 `-eru` 结尾，也属于不同类别。虽然 `-iru/-eru` 结尾的动词**很多**是一段动词，但存在常见五段动词。仅凭 `-iru/-eru`，通常可以形成有依据的初步猜测，**不能保证唯一正确**。

**更严格的理解：** 不把这个规律说成随机，也不宣称学习者能凭最后两个字母唯一推导所有动词类别。对于具体陌生词，核实词典的动词类别/活用形是可靠办法。课堂不要求学生硬背所有例词，但需认识到真实词汇积累仍有必要。

**翻译边界：** `〜た` 是过去形，中文“了”常可帮助入门，不代表每个“了”都等于日语过去形，也不代表日语非过去形只表示现在。

## 4. 逐页教学路径与问题支架

### 第 1 页：让学生提出研究方向

教师只展示三组已知词。先让学生自行写问题并说来源。例如：

- “为什么同是 る，有的变成 た、有的变成 った？”
- “是不是只要词尾前面发 e，就会变成 た？”
- “我要怎样知道某个陌生词会是哪一种？”
- “有没有别的词也这样？”

**教师提示（弱 → 强）：**

1. “这三组里，你观察到哪一点还没解释清楚？”
2. “你刚才总结的规则，在第几个词上遇到了不同情况？”
3. “如果再给你一个结尾相似的词，你准备问它什么？”
4. 必要时示范： “我想试试：结尾相似的两个词，过去形是否真的一样。” 示范后请学生生成**不同于老师示范**的一个相邻问题。

### 第 2 页：从相似中做出可检验预测

给 `切る（きる / kiru）` 和旧词 `見る（みる / miru）`。它们押同一个 `-iru` 尾音，但在现在的词汇量下，**不足以保证预测正确**。

- 允许学生预测 `切た`、`切った`、其他形式，或回答“不知道”，但让他写下理由和查证方案。
- 如果学生已经知道答案，不强迫假装不知道，让其说明证据来源或再找一个新词。
- 这里考验的不是“能否猜中切った”，而是“能否把相似性当作一个需要检验的假设”。

### 第 3 页：揭示真实差异，修正的是模型而非答案

真实例 `切る → 切った`。学生应有机会修正“凡以 -iru 结尾的词都按 る→た”之类过强的假设。

**如果学生猜对：** 也要请他说明是已知事实还是有依据的预测，并寻找可能推翻自己原规则的证据；不制造“必须猜错”。

**自主提问交接点 A：** 不马上给分类表。学生自己决定下一步该比较什么，老师仅在必要时给“找一个同类的新词，或找另一个看起来相似但变化不同的词”之类提示。

### 第 4 页：从单个例外提升到两组可复现的规律

把已知四组词放在一页，让学生自己分组、描述各组变化，并发现“词尾看起来相同≠类别相同”。此时学生可以用“换一个小字”“多了一个小字”这样的通俗表达，不要求正确使用语言学术语。

**注意：** 这一步**不能从四个例子推出一个可靠的辨别算法**。应当表述为“发现两种稳定出现的变化方式”，而不是“已经能判断每个陌生词属于哪一组”。

### 第 5 页：两项真正的新检验

提供 `寝る（ねる / neru, 睡觉）` 与 `走る（はしる / hashiru, 跑）`，让学生先作预测，表达信心和依据。若认为无法决定，鼓励其说出“我需要什么证据”，而非硬猜。

**自主提问交接点 B：** 要求学生选择一个自己想验证的第三个词（不限于课程预定的两个），并说明如何查。

### 第 6 页：核对与移交下一轮

真实答案：`寝た（ねた / neta）`、`走った（はしった / hashitta）`。学生对两组各有三个例子，但样本规模仍有限；只有查阅真实语言规范/词典，才能更牢靠了解通用程度。

总结要求是两个层次：

- **我目前能说清楚的：** 已见到两类重复出现的变法，词尾相似不能保证同一变化。
- **我目前需要查证的：** 对新的 `-iru/-eru` 动词，如何更可靠地辨别类别；是否还有第三种规律；其他结尾的动词怎么变化。

**此时才可简要告诉学生：** 语言学家把这些变化方式归在不同动词类别中。不要提前给类别名称和完整变化表。学生愿意深入时，下一课才系统探索。

## 5. 学生偏离课程预设问题时的处理

如果学生在第一页或第三页想研究另一问题（如“日语是否只靠时间词说明时间”“所有假名都能换成汉字吗”“ga 与 o 还能怎么用”），应：

1. 先记录其原话和依据，判断是否可检验。
2. 如果已有可用证据，允许顺着学生的问题研究一个小分支。
3. 证据暂不足时，请学生提出最小的验证材料，并作为“待研究问题”留下。
4. 若课堂仍需进入预设主线，诚实说“教材准备了一个不同的检验问题”，不要把它说成学生已经问了。

对于“没兴趣/不知道”的学生，先提供词汇意义、发音和对比线索，再逐级给提示。不要用“你怎么想不出来”评价。

## 6. 课堂观察记录与独立迁移测试

每次问题交接，记录：学生原话、是否独立发起、推理依据、提问时使用的支架级别（0自主/1轻提示/2半句/3教师示范）、预测是否先于揭示、结果是否改变了他的归纳、是否主动要求新的例子。

**最简独立迁移测试：** 几天后，不提示主题，给学生 `起きる（おきる / okiru, 起床）` 及词典中核实的过去形 `起きた（おきた / okita）`。只给出这两个新事实，让学生自行观察并提出一个可检验的问题。注意此测试不是判断一个词的过去形猜得对不对，而是看学生是否自主比较、新发问、提出下一项验证。

**评价纪律：** 问题数量不能替代质量；教师提示后复述的问题不算独立提出；预测成功与失败都提供信息；语言规律的归纳只按样本获得的证据范围表述。
