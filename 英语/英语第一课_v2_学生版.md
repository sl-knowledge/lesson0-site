# 英语第一课｜按中文的方式写英语，会丢掉什么？

**中文母语者学习英语 · 学生版 v2（与《英语第一课_v2_学生版.pdf》对应）**

> 今天不背单词，也不背语法。先按你自己的方式写，再一起看看会发生什么。
>
> 我们只想弄明白一件事：**同一个意思，为什么英语要换一种写法？**

---

## 第 1 页｜先按你自己的方式写

**可能用到的词：** here = 这里　cold = 冷　government = 政府　react = 反应　slow / slowly = 慢　people = 人们　angry = 生气的　rain = 下雨

### 小问题 1｜把下面三句话写成英语。写你觉得最自然的就行，不用担心对错。

① 这里很冷。 → ________________________________  
② 政府反应太慢，老百姓很生气。 → ________________________________  
③ 下雨了。 → ________________________________

*先写下来，再往下看。*

### 第 2 步｜两种语言，两套条件

| | 中文的条件 | 英语的条件 |
|---|---|---|
| **词** | 永远不变形 | 词上带"标签"：时间、单复数…… |
| **一句话怎么组织** | 像流水，一段一段往下说 | 像骨架，先定一个主语和一个主要动词 |
| **不需要的成分** | 可以不说 | 骨架上的位置必须填满 |
| **听的人靠什么** | 靠共同知道的背景，自己补上 | 靠句子里明明白白的信号 |

两套条件都是好办法。可是，**按一套条件写出来的句子，放到另一套条件下，会发生什么？**

## 第 2 页｜当一回"英语听者"

想象一个只按英语条件理解句子的人。他听句子时，会先找主语和主要动词；骨架上的每个位置，他都等着被填上；他只靠句子里的信号，不靠"心照不宣"。

很多中文母语者会这样写（也看看你自己的写法）：

**A. Here is very cold.**  
**B. Government react too slow, people very angry.**

### 小问题 3｜听完 B，英语听者能确定下面这些吗？

| 问题 | 能 | 不能 |
|---|---|---|
| 这是过去的事、现在的事，还是一直这样？ | [ ] | [ ] |
| 说的是哪一个政府？ | [ ] | [ ] |
| "反应慢"和"很生气"是什么关系？ | [ ] | [ ] |

在中文里，没说的东西，听的人会自己补上。在英语里，**空着的位置不是"没说"：要么被听错，要么信息真的丢了。**

### 第 3 步｜按英语的条件重新说

**骨架规则只有三条：**

1. 每句话必须有一个**主语**，放在最前面。
2. 每句话只能有一个**主要动词**，紧跟在主语后面。
3. 骨架上的位置**不能空着**。没有合适的东西，也得放一个进去。

### 小问题 4｜"这里很冷"和"下雨了"，都没有一个"东西"可以当主语。按规则 ③，主语的位置放什么？

主语 __________　　主要动词 __________　　其他 __________

*提示：你可以自己造一个"占位的小记号"，比如 ○。*

### 小问题 5｜只用一句话（一个主语、一个主要动词）说"政府反应太慢，老百姓很生气"。

主语 ______________________　　主要动词 __________　　其他 __________

*提示：能不能把"政府反应太慢"这整件事变成**一个东西**，放进主语的位置？*

## 第 3 页｜原来，英语就是这样说的！

① **It is cold here.**  
这里很冷。（it 没有意思，只负责占住主语的位置）

② **It is raining.**  
下雨了。

③ **The government's slow response angered the public.**  
（主语："政府迟缓的反应"；动词：使……生气）

③' **People were angry because the government reacted too slowly.**  
（另一种说法：用 because 把关系说出来）

### 小问题 7｜回到第 2 页的小问题 3。英语的这些写法，分别把哪样东西"找回来"了？

were（过去的事）→ 找回了 __________  
because → 找回了 __________  
the government → 找回了 __________

> **这就是英语。** 在"骨架必须填满、听的人只靠信号"的条件下，英语长成了这个样子：用 it 占位，用词上的标签说清时间，用 because 说清关系，用一个大名词装下整件事。按中文的样子写也不是不行，但会丢掉这些东西。这是我们今天的初步发现，英语还有更多细节，以后慢慢发现。
